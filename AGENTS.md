# Regras do projeto quiz

## Commit e push automáticos

Sempre que você concluir **qualquer** mudança neste projeto (editar, criar ou
deletar arquivos), finalize a tarefa executando imediatamente:

1. `git add -A`
2. `git commit -m "mensagem descritiva curta"`
3. `git push origin main`

Não pergunte antes de commitar/pushar: faça isso automaticamente no fim de cada
tarefa, sempre na branch `main` e enviando para o repositório no GitHub.

Regras extras:
- Mantenha o projeto em português.
- Não commite segredos ou .env.
- Se uma tarefa não alterar nenhum arquivo, não é preciso commitar.
